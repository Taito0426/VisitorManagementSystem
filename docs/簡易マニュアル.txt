====================================================================
 来館者記録管理システム　簡易マニュアル
 バージョン 1.0.0 ／ 文字コード: UTF-8
====================================================================

このマニュアルは、導入担当者および利用者向けの基本操作をまとめた簡易版です。

本システムは次の2つのアプリケーションで構成されます。
  ・管理アプリ（Windows）… 来館予約の登録、履歴照会、マスタ管理を行う
  ・受付Web（ブラウザ）  … 受付端末でQRコードを読み取り、入退館を受け付ける


====================================================================
 1. 動作環境・前提
====================================================================
・OS          : Windows 10 / 11（64bit）
・データベース: SQL Server Express（既定インスタンス名 SQLEXPRESS）
                またはクラウド版の Azure SQL Database
・ブラウザ    : Microsoft Edge / Google Chrome（受付端末）
・周辺機器    : USB QRリーダー（キーボードエミュレーション方式）
                感熱式ラベルプリンタ（ブラザー QL-800 想定・当日受付を使う場合）
   ※アプリ本体に .NET ランタイムは同梱されています（別途インストール不要）。
   ※SQL Server Express は本システムに含まれません。事前に導入してください。
・権限        : インストールは管理者権限が必要です。


====================================================================
 2. インストール
====================================================================
(1) データベースを作成します（導入担当者が1回だけ実施）。
    詳細は「導入手順書.md」を参照してください。

(2) 配布されたフォルダを任意の場所へ配置します。
    ・管理アプリ : VisitorManagement.WinFormsApp.exe
    ・受付Web    : VisitorManagement.WebReception.exe
    いずれも .NET ランタイムを同梱しているため、実行ファイルをそのまま起動できます。

(3) 受付Webは実行ファイルをダブルクリックすると起動し、
    ブラウザで http://localhost:5000 （設定した番号）を開いて使用します。

【アンインストール】
    配置したフォルダを削除してください。データベースは別途削除が必要です。

【バージョンアップ】
    新しいフォルダの内容で上書きします。
    ※ appsettings.Local.json（接続先などの設定）は上書きしないでください。


====================================================================
 3. 初期設定（接続先データベース）
====================================================================
接続先は次のファイルで設定します。

   （配置フォルダ）\appsettings.json
   （配置フォルダ）\appsettings.Local.json  ← 導入先ごとの設定はこちらを推奨

   "Database": {
     "Provider": "SqlExpress",
     "ConnectionStrings": {
       "SqlExpress": "Server=.\\SQLEXPRESS;Database=VisitorMgmt;User Id=svc_visitor;Password=***;TrustServerCertificate=True;Encrypt=False;"
     }
   }

   ・Provider : "SqlExpress"（社内サーバー）または "AzureSql"（クラウド）
   ・Server   : サーバー名\インスタンス名（例 192.168.0.10\SQLEXPRESS）
   ・Database : データベース名（既定 VisitorMgmt のままで可）

【パスワードの保護】
   接続文字列のパスワードは平文で保存せず、暗号化した値を設定できます。

     powershell -ExecutionPolicy Bypass -File scripts\Protect-Secret.ps1

   表示された「ENC:...」の値をそのまま設定ファイルに貼り付けてください。
   アプリが起動時に自動で復号します。
   ※暗号化した値は、暗号化を行ったパソコンでのみ使用できます。


====================================================================
 4. 起動とログイン
====================================================================

■ 管理アプリ
(1) VisitorManagement.WinFormsApp.exe を起動します。
(2) ログイン画面で「ログインID」と「パスワード」を入力します。

【初回起動時】
   操作ユーザーがまだ登録されていない場合、「初期セットアップ」画面が表示されます。
   最初の拠点（例：本社）と、管理者アカウントを登録してください。
   ここで登録したアカウントで、以降のマスタ登録を行います。

■ 受付Web
(1) VisitorManagement.WebReception.exe を起動します（黒い画面が表示されます）。
(2) ブラウザで受付画面のURLを開き、受付担当者のアカウントでログインします。
(3) ログイン後は「入退館受付」画面が表示され、QRコードの読み取り待ちになります。

【パスワードについて】
・8文字以上で設定してください。
・連続してログインに失敗しても自動ではロックされません。
  不審なアクセスが疑われる場合は管理者がアカウントを無効化してください。

 5. 権限（ロール）について
====================================================================
操作ユーザーには3種類の権限があり、使える機能が変わります。

   ┌──────────────────┬────────┬────────┬────────┐
   │ 機能                │ 管理者 │ 受付   │ 一般   │
   ├──────────────────┼────────┼────────┼────────┤
   │ 来館予約の登録       │   ○   │   ○   │   ○   │
   │ 予約の編集・キャンセル│   ○   │   ○   │  ○ ※1│
   │ 予約の削除          │   ○   │   ○   │   ×   │
   │ 当日受付・入退館受付 │   ○   │   ○   │   ×   │
   │ 手動退館処理        │   ○   │   ○   │   ×   │
   │ メール再送信        │   ○   │   ○   │   ×   │
   │ 会社名マスタ管理     │   ○   │   ×   │   ×   │
   │ 拠点マスタ管理       │   ○   │   ×   │   ×   │
   │ 操作ユーザー管理     │   ○   │   ×   │   ×   │
   │ システム設定確認     │   ○   │   ×   │   ×   │
   └──────────────────┴────────┴────────┴────────┘

   ※1 一般権限で編集・キャンセルできるのは、自分が登録した予約だけです。
       他の担当者が登録した予約は一覧にも表示されません。
       予約を取りやめる場合は「削除」ではなく「キャンセル」を使用します
       （キャンセルすると招待者へ通知メールが送られ、QRコードが無効になります）。

【履歴・予約の閲覧できる範囲】
   ・管理者 : すべての拠点・すべての件数
   ・受付   : 自分の所属拠点の全件
   ・一般   : 自分が登録した予約のみ

※権限がない機能はメニューやボタンが表示されません。

 6. 基本業務の流れ
====================================================================

■ 事前予約 → QR発行 → 入館 → 退館
(1) [管理アプリ] メニュー「来館予約管理」→「新規登録」。
    来館日時・訪問先担当者・目的と、代表者の情報を入力します。
    同行者がいる場合は、下の表に氏名を追加します。
(2) 保存すると、QRコードが自動発行され、来館案内メールが送信されます。
      ・招待者（代表者）宛     … 当日提示していただくQRコード付き
      ・予約登録者（自分）宛   … 控え。招待者が紛失した際は転送で対応できます
    保存直後にQRコード画面が開くので、必要なら画像として保存できます。
(3) 来館当日、受付端末の [受付Web] でQRコードを読み取ります。
      ・1回目の読み取り → 入館（グループ全員が「入館中」になります）
      ・2回目の読み取り → 退館（グループ全員が「退館済」になります）
      ・3回目以降       → エラー表示（記録は変わりません）
    ※これは事前予約のQRコードの動作です。当日受付のQRコードは
      発行時点で入館済みのため、最初の読み取りが退館になります（下記参照）。
(4) 読み取り結果は画面に大きく表示され、しばらくすると自動的に消えます。

  ★QRコードは代表者お一人にのみ発行されます。
    同行者の方は個別のQRコードを持たず、代表者のQRコード1枚で
    グループ全員の入館・退館手続きが完了します。

  ・QRコードが使える時間帯は「来館予定時刻の30分前から2時間後まで」です。
    時間外に読み取るとエラーになります。

■ 当日受付（予約なしで来館された方）
(1) [受付Web] 受付画面の「予約がない方はこちら（当日受付）」を押します。
(2) 会社名・お名前などを入力します（メールアドレスは任意です）。
    同行者がいる場合は、下の表に氏名を追加します。
(3) 「登録してQRコードを発行」を押すと、次の処理がまとめて行われます。
      ・★登録した時点で「入館」として記録されます（登録時刻＝入館時刻）
      ・グループ全員が「入館中」になります
      ・QRコードラベルが印刷されます
(4) ラベルを代表者にお渡しします。
(5) ★お帰りの際に、そのQRコードを受付端末で読み取ると「退館」になります。

  ★当日受付のQRコードは「退館用」です。
    受付にお越しの時点で入館手続きが完了しているため、
    発行直後に読み取る必要はありません（読み取ると退館扱いになります）。

  ※当日受付の画面は日本語と英語を併記しています。
  ※メールアドレスを入力した場合のみ、来館案内メールが送信されます。
  ※あとから合流する同行者の方は、その時点で改めて当日受付として登録してください
    （既存の予約に追加することはできません）。
  ※当日受付のQRコードも有効期限は受付時刻から2時間です。
    2時間を超えて滞在された場合は、管理アプリの「手動退館処理」で退館してください。

■ 代表者と同行者が別々に退館する場合（手動退館処理）
(1) [管理アプリ] メニュー「手動退館処理」を開きます。
(2) 氏名や来館日で入館中の方を検索し、対象者を選んで「退館処理」を押します。
(3) 選択した方だけが「退館済」になります（グループの他の方は入館中のままです）。

■ メールが届かない・紛失したと連絡があったとき
(1) [管理アプリ]「来館予約管理」で対象の予約を選びます。
(2) 「メール再送信」を押すと、招待者と予約登録者の双方へ送り直します。
  ※当日受付で登録した予約、退館済み・キャンセル済みの予約は再送信できません。

■ 予約の取り消し
(1) [管理アプリ]「来館予約管理」で対象の予約を選び「キャンセル」を押します。
(2) QRコードが無効になり、招待者へキャンセル通知メールが送信されます。
  ※すでに退館済みの予約はキャンセルできません。
  ※入館・退館の記録がある予約は「削除」できません（履歴を残すため）。

■ 履歴の確認
・[管理アプリ]「履歴照会」で、入退館履歴とメール送信履歴をタブで切り替えて確認します。
・期間・氏名・会社名・拠点で絞り込み、CSVファイルへ出力できます。
・データベースに残るのは直近3か月分です。それ以前の期間を指定すると、
  アーカイブ済みCSVファイルの保管場所が画面に案内されます。

 7. 管理者向け機能
====================================================================
※以下は管理者権限のアカウントのみ表示されます。

・拠点マスタ管理     : 拠点の登録・編集。ラベル印刷用の社名・ロゴ画像・
                       ラベルサイズを設定します。
                       ※拠点が1件だけの場合、各画面の拠点選択欄は表示されません。
・会社名マスタ管理   : 来館予約の入力補助に使う会社名を登録します。
・操作ユーザー管理   : アカウントの登録・編集・無効化、パスワード変更。
                       ★権限ロールと所属拠点は必ず設定してください（必須項目です）。
                       ※拠点の異動はこの画面で所属拠点を変更して対応します。
                       ※有効な管理者が0人になる変更はできません。
・システム設定確認   : 現在のデータベース方式・メール送信方式・印刷方式などを
                       確認できます（表示のみ・変更はできません）。
・サンプルデータ初期化: デモ版のときのみ表示されます。
                       デモ用データを初期状態に戻します。

 8. 困ったときは（トラブルシューティング）
====================================================================
● 起動時に「アプリケーションの起動に失敗しました」と出る
  → SQL Server が起動しているか、appsettings.json の接続先（サーバー名・
    インスタンス名・パスワード）が正しいかを確認してください（本マニュアル 3章）。
  → 接続文字列を「ENC:」の暗号化値にしている場合、暗号化したパソコンと
    別のパソコンでは復号できません。そのパソコンで暗号化し直してください。

● QRコードを読み取っても何も起きない
  → QRリーダーが「読み取った値の最後にEnterキーを送る」設定になっているか
    確認してください。本システムはEnterを合図に受付処理を行います。
  → 画面上の入力欄にカーソル（フォーカス）があるか確認してください。
    画面をクリックすると入力欄に戻ります。

● 「このQRコードの有効期限が切れています」と出る
  → QRコードは来館予定時刻の30分前から2時間後までしか使えません。
    受付担当者が「当日受付」として登録し直すか、管理アプリから
    「メール再送信」を行うと有効期限が再設定されます。

● 「受付可能時間の前です」と出る
  → 来館予定時刻の30分前になると読み取れるようになります。

● 「このQRコードは既に退館処理済みです」と出る
  → 3回目以降の読み取りです。すでに退館の受付が済んでいます。

● 「他の受付端末で処理中です」と出る
  → 複数の端末でほぼ同時に読み取った場合に表示されます。
    しばらくしてからもう一度読み取ってください。

● メールが送信されない
  → [管理アプリ]「履歴照会」の「メール送信履歴」タブで、結果が「失敗」の
    レコードのエラー内容を確認してください。
    設定（APIキー・SMTPサーバー）の誤りが原因のことが多いです。
  → メール送信に失敗しても予約の登録自体は完了しています。

● ラベルが印刷されない
  → プリンタのドライバと b-PAC SDK がインストールされているか確認してください。
  → appsettings.json の Printing:LbxTemplatePath にラベルテンプレート（.lbx）の
    パスが設定されているか確認してください。
  → 印刷に失敗しても当日受付の登録自体は完了しています。

● メニューに項目が表示されない
  → 権限（ロール）により表示が制限されています。必要な場合は管理者へご相談ください。

● 一般権限で予約一覧に何も表示されない
  → 一般権限では「自分が登録した予約」のみ表示されます。仕様どおりの動作です。

● 一般権限で「削除」「メール再送信」のボタンが見当たらない
  → 一般権限では削除とメール再送信は行えません。予約を取りやめる場合は
    「キャンセル」を、メールの再送が必要な場合は受付・管理者へご依頼ください。

● ログを確認したい
  → 管理アプリ : 実行ファイルと同じフォルダの logs\app-YYYYMMDD.log
  → 受付Web    : 起動した黒い画面に表示されます。
