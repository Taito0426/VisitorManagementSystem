====================================================================
 wwwroot/js に同梱している外部ライブラリ
====================================================================

受付Webは自己完結型で発行し、LAN内・オフライン環境での運用を前提と
するため、外部CDNを参照せずファイルを直接同梱している。
更新する場合は下記の入手元から取得し、SHA-256 を照合すること。

--------------------------------------------------------------------
 jsQR.js
--------------------------------------------------------------------
  用途      : スマホ・PCのカメラ映像からQRコードを読み取る（受付画面）
              ブラウザ標準の BarcodeDetector が使えない環境
              （iOS Safari など）でのフォールバックとして使用する。
  バージョン: 1.4.0
  入手元    : https://cdn.jsdelivr.net/npm/jsqr@1.4.0/dist/jsQR.js
              （npm パッケージ jsqr の dist をそのまま配置。無改変）
  リポジトリ: https://github.com/cozmo/jsQR
  ライセンス: Apache License 2.0
              全文は jsQR.LICENSE.txt を参照。
  SHA-256   : bc40c8a15196236b2314db0856f72ca0b49980cd5413b8c852a7349f5fee0859

  ※ 改変せずに配置しているため、更新時はファイルを差し替えたうえで
     本ファイルのバージョンとSHA-256を書き換えること。
